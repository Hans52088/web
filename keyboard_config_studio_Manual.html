⌨️ 鍵盤配置工作室 - 用戶操作手冊

版權所有 ＆ 製作：WHY

歡迎使用鍵盤配置工作室！本手冊將引導您熟悉五大核心功能，輕鬆自訂專屬的元書輸入法鍵盤配置。

1. 匯入 .cskin 皮膚檔

系統支援快速匯入 .cskin 格式的皮膚包。只需將檔案拖放至上方匯入區，或點擊「選擇 .cskin」按鈕上傳。系統會自動解壓並將您的佈局、配色、上下滑及長按等配置載入至對應分頁中，無須逐一設定，立刻開始編輯。

2. 可視化的修改鍵盤配置

進入「佈局與配色」分頁，您可以透過直觀的視覺化介面編輯鍵盤佈局。左側可調整按鍵寬度、高度及間距等參數，下方則能新增或刪除按鍵排數。右側提供即時預覽，支援中/英文及直/橫式切換，真正實現「所見即所得」。



3. 文字與鍵盤配色

在「鍵盤配色選項」中，您可輕鬆設定鍵盤的日/夜間模式。支援系統智慧切換、統一配色或獨立設定。從鍵盤底色、一般按鍵、系統按鍵到文字顏色皆能點擊色塊直接挑選，右側預覽畫面會立即反映您的色彩設計。

4. 按鍵上下滑及長按輸出內容

切換至「上下滑與長按」分頁，點選預覽圖中的按鍵即可編輯。您可以設定上滑/下滑的輸出類型(如快捷鍵、符號)、視覺圖示與顏色。點擊「長按配置」則可新增或調整長按時彈出的選單內容，全面自訂按鍵的進階功能。



5. 修改後存為 .cskin 皮膚檔

所有編輯完成後，不需手動複製繁雜的程式碼。只需點擊匯入區塊右側的「💾 匯出 .cskin」按鈕，系統會將您修改後的佈局、配色與快捷操作等所有設定，一鍵重新打包並下載為新的 .cskin 皮膚檔，直接套用至設備。
